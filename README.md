# @flun/passport-desktop-win32-x64-msvc

This package provides the **x86_64-pc-windows-msvc** native binary for Windows Hello operations, built from the [passport-desktop](https://github.com/OpenFlun/passport-desktop) source.

It is intended to be used as a dependency in Node.js projects that need to call Windows Hello APIs directly.

## Installation

```bash
npm install @flun/passport-desktop-win32-x64-msvc
